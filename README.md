# letsdefend-writeups
This repository contains my writeups for various LetsDefend SOC alerts, monitoring alerts, and cybersecurity challenges.

The purpose of this repository is to not only document what I found during each investigation, but also how and why I approached the investigation the way I did. I believe that completing a lab or challenge is valuable, but writing out the process forces me to explain my reasoning, justify my decisions, and better understand the evidence behind each conclusion I made. My goal is to avoid simply saying I did something because it "felt right" or relying on intuition alone. Instead, I want to develop the habit of making evidence-based decisions that I can clearly explain.

These writeups also serve as a way for me to improve my technical documentation and to practice communicating security findings in a clear, structured, and understandablae way. Where applicable, I use MITRE ATT&CK terminology, the 5 W's, screenshots, indicators of compromise, and my step-by-step analysis to document both my final findings and the reasoning behind the investigation process.
