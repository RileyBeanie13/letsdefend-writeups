# letsdefend-writeups

This repository contains my writeups for LetsDefend SOC alerts and monitoring alerts.

The purpose of this repository is to document not only what I found during each investigation, but also how and why I approached it the way I did. Completing a lab is valuable, but writing out the process forces me to explain my reasoning, justify my decisions, and better understand the evidence behind each conclusion. My goal is to avoid saying I did something because it "felt right" or relying on intuition alone. Instead, I want to build the habit of making evidence-based decisions that I can clearly explain.

These writeups also help me improve my technical writing, since an investigation is only as useful as the report that comes out of it. In a real SOC, the next analyst or the incident response team has to be able to pick up my notes and understand what happened, what I checked, and why I reached the verdict I did, without having to redo the investigation themselves. Writing each one up is my way of practicing that, and of keeping a record I can look back on to see how my approach has changed over time.
